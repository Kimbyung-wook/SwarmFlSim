# 10. 문제 해결

증상별로 찾는다. 빌드와 코드 수준 문제는 [개발자 매뉴얼 11장](../41_dev/11_troubleshooting.md).

프로세스 로그는 실행기를 썼다면 `out/p0_demo/<모드>-<시각>/<프로세스>.log`에 있다.

## 10.1 지도

| 증상 | 원인 | 조치 |
|---|---|---|
| 지도가 저해상도이고 지형이 평평하다 | 로컬 타일이 없다. 도구 막대에 `지도 내장 · 지형 타원체`로 표시된다 | [1.2](01_install.md#12-지도-자료-선택)대로 타일을 만든다. 없어도 실행에는 지장 없다 |
| 엔티티가 화면에 안 보인다 | 카메라가 다른 곳을 본다 | 도구 막대의 `전체`를 누른다 |

## 10.2 연결

| 증상 | 원인 | 조치 |
|---|---|---|
| UI에 연결 표시가 없다 | 브리지가 없거나 주소가 다르다 | URL의 `bridge=`와 브리지의 포트를 맞춘다. 기본 `ws://127.0.0.1:8765/bus` |
| `목 소스`로 표시된다 | URL에 `source=bus`가 없다 | 2장의 주소로 연다. 또는 도구 막대에서 `버스(브리지)`를 고른다 |
| 도구 막대에 `시뮬레이션 응답 없음` | Core가 멈췄거나 죽었다 | Core 로그를 본다 |
| 포트 때문에 실행기가 시작되지 않는다 | 다른 실행이 포트를 쓰고 있다 | `--base-port`, `--bridge-port`, `--ui-port`, `--monitor-port`로 바꾼다 |

## 10.3 명령과 움직임

| 증상 | 원인 | 조치 |
|---|---|---|
| 임무 패널이 `REJECTED`, 사유 `unsupported task` | 이 MA가 지원하지 않는 작업이다 | [3.6](03_scenario.md#36-자율-플러그인-autonomy)의 표를 본다. 기본 MA는 `track`, `strike`, `jam`을 수행하지 않는다 |
| 항로(Route) 전송이 `REJECTED` | flocking은 Route를 지원하지 않는다 | `waypoint`를 쓴다 |
| `StrikeActivity`가 `REJECTED`, 사유 `out_of_fov` | 조준점이 발사 기체 기준 탐색 FOV 밖이다(DEC-066) | 정상 판정이다. 플러그인이 보낸 조준점을 확인한다 |
| `StrikeActivity`가 IMPACT인데 대상이 그대로다 | IMPACT는 유도 객체의 도달만 뜻한다(DEC-067) | 효과는 `truth/event/kill`로 판단한다 |
| 상태가 수행과 수락 순서가 바뀌어 보인다 | 데이터링크 지연·지터 때문이다 | 판정에는 영향이 없다 |
| 명령을 보내도 기체 일부가 안 움직인다 | 링크가 끊겼거나 재밍 구역 안이다 | Traffic Monitor에서 손실 사유를 본다([7장](07_link.md#72-메시지가-사라지는-이유)) |
| 배속 버튼이 꺼져 있다 | realtime은 배속 1로 고정이다. 재생 중에도 꺼진다 | lockstep으로 실행한다 |

## 10.4 시나리오

| 증상 | 원인 | 조치 |
|---|---|---|
| `validate`가 INVALID | 스키마 또는 의미 오류 | 출력의 경로를 고치고 다시 돌린다 |
| `validate`는 통과하는데 Core 로그에 `scenario rejected` | 25자 초과 ID, 재머 2개, `dof5`·`dof6`, 범위 밖 값 등 Core 검사 | [3.9](03_scenario.md#39-검사-항목-요약) |
| 기체가 시작하자마자 사라진다 | DEM 지형보다 낮은 고도에서 시작했다 | 시작 고도를 올린다(DEC-060) |
| 매개변수가 안 바뀐다 | 이름이 틀렸거나 범위 밖이거나 실행 중 변경 불가 항목이다 | UI 매개변수 패널의 거부 사유를 본다 |

## 10.5 lockstep

| 증상 | 원인 | 조치 |
|---|---|---|
| 시작했는데 프레임이 안 간다 | 참여자 ID가 시나리오 `participants`와 다르거나 프로세스가 안 떴다 | [4.4](04_run.md#44-lockstep), Core 로그의 대기 목록을 본다 |
| 도구 막대에 참여자 대기 표시 | 참여자가 죽었다 | 참여자를 다시 띄우고 리셋 후 시작한다 |
| 목표 배속이 안 나온다 | Python Agent가 따라가지 못한다 | Agent를 나누거나 배속을 낮춘다 |

## 10.6 기록과 재생

| 증상 | 원인 | 조치 |
|---|---|---|
| MCAP을 열지 못한다 | Logger가 정상 종료되지 않았다 | Ctrl+C로 끝낸다. 강제 종료하면 파일이 닫히지 않는다 |
| 재생 중 프레임 누락 표시 | 고배속에서 수신자가 못 따라간다(DEC-042) | `--rate`를 낮춘다 |
| 재생 중 명령을 보낼 수 없다 | 정상이다. 재생 URL은 `gcs=`를 비운다 | |
