# 10. QA harness

> Source: [docs/41_dev/10_qa.md](../../41_dev/10_qa.md) at commit `f7bcbac`.

Tools that start real processes and test the full path are in [qa/](../../../qa/). [21_qa_report.md](../../21_qa_report.md) (Korean) holds the test descriptions, pass criteria and results.

## 10.1 Running

Finish the C++ build and `uv sync` first.

```bash
uv run --with psutil python qa/run_qa.py --list
```

```bash
uv run --with psutil python qa/run_qa.py --only 001,010
```

| Option | Meaning |
|---|---|
| `--list` | List of tests |
| `--only <number,...>` | Run only some. All if absent |
| `--build-dir <dir>` | C++ build directory |

Results go to `qa/out/<TC>/` (process logs, MCAP, `.pb`) and `qa/out/results.json`.

## 10.2 Test groups

| Group | Contents |
|---|---|
| s1~s5 | Formation, swarm multi-mission, imperfect links, target and equipment declarations, mixed models |
| s6 | Load with 50 and 100 vehicles, lockstep and realtime |
| Control | Pause, resume, step, rate, reset, mode switching, invalid `SimCommand` |
| Mission commands | Normal path, consecutive and conflicting commands, invalid values |

Scenarios are in [qa/scenarios/](../../../qa/scenarios/) and use purpose prefixes such as `qa_s*`, `qa_p5_*`, `qa_los_*`, `qa_dem_*`, `gw_*`. The process group and observer are `Stack` and `Observer` in [qa/harness.py](../../../qa/harness.py).

## 10.3 Determinism diagnostics

Runs the same scenario several times in lockstep and compares the trajectories.

```bash
uv run python qa/diag_determinism.py --frames 3000 --seed 7 --runs 2
```

| Option | Meaning |
|---|---|
| `--scenario <file>` | Target scenario |
| `--frames`, `--seed`, `--runs` | Number of frames, seed, number of repetitions |
| `--verbose` | Verbose output |

Check changes that affect lockstep with this diagnostic ([chapter 9](09_contributing.md)).

To compare `LinkOutcome` and GCS receptions as well, use `qa/gw_plan.py --lockstep-det`. It repeats a same-seed lockstep run and compares the first 60 s with run 1.

```bash
uv run python qa/gw_plan.py --lockstep-det qa/out/det --det-runs 8 --variants noloss,loss,fault_noloss,fault_loss,payload
```

## 10.4 Fault injection

Injects faults into a running bus. Kinds and effects are in [7.4](../42_user/07_link.md#74-fault-injection) of the user manual.

```bash
uv run python qa/inject_fault.py --connect tcp/127.0.0.1:17601 --entity uav-003 --kind LINK_CUT --duration 10
```
