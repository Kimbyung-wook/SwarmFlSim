# User manual

> Source: [docs/42_user/README.md](../../42_user/README.md) at commit `f0d0533`.

- Readers: researchers and operators who write scenarios, run the simulator, operate the UI and replay recordings without changing code.
- New to the project? Read the project overview first (`../40_overview.md`, planned). For building, follow chapters 1–2 of the [developer manual](../41_dev/README.md).
