# 운용 시나리오 수행률 (S1~S6)

- 목적: [50_operational_scenarios.md](50_operational_scenarios.md)의 S1~S6을 지금 시스템(UI, 시뮬레이터, 기본 MA, Gateway, 시험 도구)으로 어디까지 운용할 수 있는지 단계별로 판정한다.
- 기준: `wp0-contracts` 06c8f79, 계약 0.24.0. 시나리오 문서는 계약 0.23.0 시점에 쓰였으므로 그 뒤 들어온 DEC-106 구현(IMP-AGT-060, 기본 MA의 Track·Jam·Strike·센서 지향)과 DEC-107(재머 소유 기체 수신 면제)을 반영해 다시 판정했다.
- 갱신: `wp0-contracts` 1f2f147. §4 UI 보완(IMP-UI-085~093)을 반영해 다시 판정했다. 계약은 그대로 0.24.0이다.
- 방법: 정적 대조다. 단계마다 필요한 명령·동작을 UI 코드(`ui/src/model/commands.ts`, 임무 창·명령 패널), 기본 MA(`algorithms/`), Gateway 수신 규칙(`gateway/README.md`), 시나리오 형식(`docs/42_user/03_scenario.md`), 시험 도구(`qa/inject_fault.py`)와 맞춰 봤다. 시나리오를 실제로 돌려 확인하지는 않았다.

## 1. 판정 기준

### 1.1 단계 판정

| 판정 | 점수 | 뜻 |
|---|---|---|
| 가능 | 1 | 시나리오가 의도한 동작을 지금 시스템으로 낼 수 있다 |
| 부분 | 0.5 | 일부만 되거나, 대체 동작(시나리오 문서의 "기대 결과(현재)")만 된다 |
| 불가 | 0 | 기능이 없다 |

### 1.2 수행 수단

| 수단 | 뜻 |
|---|---|
| UI | GCS UI 조작(임무 창, 항로, 명령 패널, 매개변수 패널) |
| 사전 | 시나리오 JSON에 미리 적는다(`mission_plan`, `engagement_criteria`, MA 변수). 실행 중에는 바꿀 수 없다 |
| 외부 | Gateway에 붙은 외부 C2(예: `qa/gw_ext_client.py`) |
| 도구 | 시험 진행자 명령줄 도구(`qa/inject_fault.py`) |
| 자동 | Core·Datalink·기본 MA·런타임이 스스로 한다 |

### 1.3 수행률

- **시스템 수행률**: 단계 점수의 합 ÷ 단계 수. 수단은 따지지 않는다.
- **UI 수행률**: 운용자(GCS·시험 진행자)가 하는 단계 가운데 UI만으로 할 수 있는 비율이다.

- 이전 판정(06c8f79)은 시스템 40.0/46 = 87%, UI 17/26 = 65%였다. 오른 몫은 모두 UI 보완(IMP-UI-085~093)에서 왔다.

- 시나리오 6개 모두 시작부터 종료 조건까지 돌릴 수 있다. 못 하는 단계는 시나리오 문서가 "기대 결과(현재)"로 정한 대체 동작으로 지나간다.
- 시나리오 의도를 끝까지 내는 것은 S2·S3·S4이고, 세 시나리오 모두 UI만으로 운용할 수 있다.
- 운용자 단계는 모두 UI로 할 수 있다. 다만 S6-1의 편대 소속 MA 변수 `group`은 실행 중 바꿀 수 없어 시나리오에 미리 적는다.
- 남은 차이는 MA 기능 쪽이다: 공유 트랙 활용(OPN-082), 탐색 패턴(OPN-081), 리더 재선출(OPN-080), 패키지 상태(OPN-083), 항로점 정찰 센서 지향, 기체 쪽 DMS(OPN-084).

## 5. 시나리오 문서와 다른 점

[50_operational_scenarios.md](50_operational_scenarios.md) §0.2의 상태 열은 계약 0.23.0 기준으로 쓰였고, 아래 차이를 반영해 갱신했다.

- `TrackTask`, `JamTask`, `SensorCommand`가 미구현에서 구현됨으로 바뀌었다. 센서 지향은 track·search_area·strike에 한해서다(DEC-106, IMP-AGT-060).
- `StrikeTask`와 `StrikeCommand`가 부분에서 구현됨으로 바뀌었다. 기본 MA `waypoint`·`formation` 리더가 수행한다.
- `JammerCommand`가 부분에서 구현됨으로 바뀌었다.
- 링크 상실 중 발사 금지와 재밍 유지 규칙(DEC-106(6))이 구현됐다. 그래서 S4 "미구현 기능 요약"의 OPN-079 항목이 해소됐다.
- 재밍 판정에 재머 소유 기체 면제가 추가됐다(DEC-107).
- `MA_TxDataPayloadCommand`·`MA_RxDataPayload`는 Gateway 외부 교환 봉투로 쓰인다(DEC-111). 기체 쪽 데이터 전송(DMS)은 여전히 없다.
