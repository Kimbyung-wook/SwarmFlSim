# 10. QA 하니스

실제 프로세스를 띄워 전체 경로를 시험하는 도구가 [qa/](../../qa/)에 있다. 시험 설명과 판정 기준, 결과는 [21_qa_report.md](../21_qa_report.md)가 기준이다.

## 10.1 실행

먼저 C++ 빌드와 `uv sync`를 끝낸다.

```bash
uv run --with psutil python qa/run_qa.py --list
```

```bash
uv run --with psutil python qa/run_qa.py --only 001,010
```

| 옵션 | 뜻 |
|---|---|
| `--list` | 시험 목록 |
| `--only <번호,...>` | 일부만 실행. 없으면 전체 |
| `--build-dir <dir>` | C++ 빌드 디렉터리 |

결과는 `qa/out/<TC>/`(프로세스 로그, MCAP, `.pb`)와 `qa/out/results.json`에 남는다.

## 10.2 시험 구성

| 묶음 | 내용 |
|---|---|
| s1~s5 | 편대, 군집 다중 임무, 불완전 링크, 표적·장비 선언, 혼합 모델 |
| s6 | 부하 50대·100대, lockstep과 realtime |
| 통제 | 일시정지·재개·스텝·배속·리셋, 모드 전환, 잘못된 `SimCommand` |
| 임무 명령 | 정상 경로, 연속·충돌 명령, 잘못된 값 |

시나리오는 [qa/scenarios/](../../qa/scenarios/)에 있고 `qa_s*`, `qa_p5_*`, `qa_los_*`, `qa_dem_*`, `gw_*`처럼 목적별 접두어를 쓴다. 프로세스 묶음과 관측기는 [qa/harness.py](../../qa/harness.py)의 `Stack`, `Observer`다.

## 10.3 결정성 진단

같은 시나리오를 lockstep으로 여러 번 돌려 궤적 차이를 본다.

```bash
uv run python qa/diag_determinism.py --frames 3000 --seed 7 --runs 2
```

| 옵션 | 뜻 |
|---|---|
| `--scenario <file>` | 대상 시나리오 |
| `--frames`, `--seed`, `--runs` | 프레임 수, 시드, 반복 횟수 |
| `--verbose` | 자세한 출력 |

lockstep에 영향을 주는 변경은 이 진단으로 확인한다([9장](09_contributing.md)).

## 10.4 고장 주입

실행 중인 버스에 고장을 넣는다. 종류와 효과는 사용자 매뉴얼 [7.4](../42_user/07_link.md#74-고장-주입).

```bash
uv run python qa/inject_fault.py --connect tcp/127.0.0.1:17601 --entity uav-003 --kind LINK_CUT --duration 10
```
